# PlagiarismGuard: Multi-Factor AI & Integrity Engine 🛡️

An enterprise-grade, local-first plagiarism and AI-generation detection system. Built to identify both traditional copy-pasting and synthetic text generated by LLMs (ChatGPT, Claude, Gemini) using advanced statistical mathematics.

## 🚀 Core Features
* **Multi-Factor AI Detection:** Utilizes Shannon Entropy (Perplexity) and Numpy-based Burstiness calculations to detect mathematically uniform synthetic writing.
* **Targeted Web Scraping:** Uses TF-IDF rarity weighting to isolate highly unique sentences and verify them against live Google Search results.
* **Self-Learning Vector Database:** Automatically tokenizes and vectorizes uploaded documents into a local Scikit-Learn sparse matrix for cross-referencing without external API costs.
* **Multi-Format & OCR Pipeline:** Native support for `.pdf`, `.docx`, and `.txt`. Includes an automatic Tesseract OCR fallback to extract text from embedded images.
* **Educator Dashboard:** Role-based access control featuring an analytics dashboard (built with Chart.js) to monitor system-wide integrity scores.

## 🛠️ Tech Stack
* **Backend:** Python 3, Flask, SQLite3
* **Machine Learning/NLP:** Scikit-Learn (TF-IDF, Cosine Similarity), Math/Numpy (Information Entropy)
* **Extraction:** `pdfplumber`, `python-docx`, Tesseract OCR (`pytesseract`)
* **Frontend:** HTML5, CSS3 (Glassmorphism UI), Vanilla JavaScript, Chart.js

## ⚙️ Installation & Setup
1. Clone the repository: `git clone https://github.com/yourusername/PlagiarismGuard.git`
2. Install dependencies: `pip install -r requirements.txt`
3. Install Tesseract OCR on your machine and ensure the executable path is mapped in `logic.py`.
4. Run the application: `python app.py`
5. Access the scanner at `http://127.0.0.1:5000` and the Admin Dashboard at `http://127.0.0.1:5000/admin`.
